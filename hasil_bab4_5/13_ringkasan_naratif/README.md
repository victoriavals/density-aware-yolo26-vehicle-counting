# 13 — Ringkasan Naratif per Tahap

Catatan naratif yang ditulis pada setiap tahap eksperimen, berguna untuk menelusuri
**mengapa** sebuah keputusan diambil, bukan sekadar hasil akhirnya.

| Berkas | Isi |
|---|---|
| `grid_search.md` | Rincian sembilan kombinasi α dan σ, matriks marginal, pola interaksi diagonal, epoch terbaik tiap kombinasi |
| `catatan_run.md` | Catatan pelatihan delapan varian: durasi, VRAM, epoch berhenti, kejadian selama 45 jam pelatihan |
| `ringkasan_evaluasi.md` | Ringkasan evaluasi terstratifikasi dan uji hipotesis versi awal (sebelum aturan sel minimum diterapkan) |
| `validasi_oklusi.md` | Ringkasan validasi proksi oklusi beserta kalimat interpretasi siap adaptasi |

⚠️ `ringkasan_evaluasi.md` memuat angka **sebelum FASE 1** (34 sel, ambang oklusi 0,35).
Angka yang berlaku adalah versi 24 sel di [`../04_ablasi_deteksi/`](../04_ablasi_deteksi/).
Berkas lama sengaja dipertahankan sebagai jejak proses, bukan sebagai rujukan angka.
